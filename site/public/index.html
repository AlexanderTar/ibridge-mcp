Contacts

How it works

Connect in four steps

  1. Add the connector.In Claude, open Settings → Connectors, add a custom connector and paste the address. https://mcp.ibridge.fyi/mcp
  2. Sign in with Apple.
  3. Choose a plan.US$1.99/month or US$19.99/year.
  4. Connect iCloud.Enter your iCloud address and an app-specific password.

Using Claude Code?

claude mcp add --transport http ibridge https://mcp.ibridge.fyi/mcp

FAQ

Is iBridge made by Apple?

No. It's an independent, unofficial service.

Which assistants can use it?

Claude, GrokBot and any assistant that supports MCP connectors.

Which password do I give it?

An app-specific password from your Apple Account, never your main one.

How much does it cost?

US$1.99/month or US$19.99/year. Running it yourself is free.

Can I run it myself?

Yes. It's open source. Run it in Claude Desktop or Claude Code, or self-host it with Docker.
