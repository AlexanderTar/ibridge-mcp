iBridge

iBridge lets an AI assistant such as Claude read and manage your iCloud Mail, Calendar and Contacts, using the standard Model Context Protocol (MCP). You choose what it may do, and you can cut it off at any time.

iBridge is an unofficial service. It is not affiliated with Apple, and it is not endorsed by Apple. iCloud is a trademark of Apple Inc.

The product site is ibridge.fyi.

  1. In Claude, open Settings, then Connectors, and add a custom connector.Paste the address above.
  2. Claude opens a sign-in page here.{% if identity %}Sign in with Apple{% if price.is_some() %}, choose a plan{% endif %}, then enter{% else %}Enter{% endif %} your primary iCloud address and an app-specific password. Never use your main Apple ID password.
  3. Approve, and you are connected.

In Claude Code, run claude mcp add --transport http ibridge {{ connector }}. Other assistants that support MCP sign-in work the same way. For one that cannot sign in, make a personal API key on your account page.

What to know first

  • Your app-specific password is stored encrypted under a key that only your connected app holds, so we cannot decrypt it from storage. There is still a risk while you sign in and while a request runs. The privacy policy explains both plainly.
  • Mail, calendar and contact text can carry instructions meant for the assistant.
  • When you disconnect, revoke the app-specific password at Apple too.

Your account: see what is connected, revoke an app or key, make an API key, or delete everything. See also the privacy policy and the terms of use.
