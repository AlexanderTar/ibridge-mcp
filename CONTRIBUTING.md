# Contributing

This project uses the [Developer Certificate of Origin](https://developercertificate.org/) version 1.1. There is no contributor licence agreement.

Sign off every commit:

```sh
git commit -s
```

That adds a `Signed-off-by` line. By adding it, you certify the DCO: you wrote the change, or you can submit it under the project's Apache-2.0 licence.

Commits are also GPG-signed. Do not pass `--no-gpg-sign` or set `commit.gpgsign` to false.
