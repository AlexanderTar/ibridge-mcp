Design system

Tokens and components for ibridge.fyi. Every value lives in tokens.css (mirrored in tokens.json); components in components.css use only those tokens. The logo here is a stand-in until an icon is chosen.

Colour

Light is the default; dark follows the system setting. Teal is the only interactive colour. Coral is decorative (icon, rules, eyebrows via its darker text shade). Both columns are read live from tokens.css; contrast is against --color-bg in the same scheme.

Typography

System font stack (--font-sans): no web-font download, nothing fetched from a third party. Headings are bold with tight negative tracking; body is 17 px at 1.55. Display, H1, H2 and lede scale fluidly between phone and desktop (values shown as min → max).

Copy icon button and Try-asking row

The production copy box uses an icon button: <button aria-label="Copy"> holding .icon-copy and .icon-done. While data-copied is set the icon becomes a tick of the same size, with no word and no layout shift; copy.js sets it for 2 seconds and announces "Copied" in a visually hidden live region. .try-asking with .prompt-list shows example questions as quiet pills: a plain list, nothing to press.

FAQ accordion

.faq of native <details>: keyboard and screen-reader support for free; chevron rotates (instant with reduced motion).

Is iBridge made by Apple?

No. iBridge is an unofficial service. It is not affiliated with or endorsed by Apple. iCloud is a trademark of Apple Inc.

Which password do I use?

An app-specific password. Never use your main Apple ID password.

Callout and access modes

.callout for security notes (--warn uses coral). .access-modes explains read-only and full access as a plain list with a tinted left rule: no pill, fill or shadow, so it never looks like a control someone could tap. Its wording matches the real connect page, where read-only is a checkbox.

Encrypted under your key

Your app-specific password is stored encrypted under a key only your connected app holds.

Never your main password

Use an app-specific password, never your main Apple ID password.

  • Read-onlyReads, but cannot send, move, change or delete anything.
  • Full accessReads and manages your mail, events, reminders and contacts.
