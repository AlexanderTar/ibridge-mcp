MCP server for iCloud

The bridge between iCloud and your AI assistant.

ibridge lets Claude and other AI assistants read and manage your iCloud Mail, Calendar, Reminders and Contacts. Choose read-only or full access, and revoke it any time.

01

What it does

ibridge is an MCP server. It gives your assistant the iCloud data you already have, in four apps.

Mail

Read your inbox. With full access, manage messages too.

Calendar

See what's coming up. With full access, manage events too.

Reminders

Check your lists. With full access, manage reminders too.

Contacts

Look people up. With full access, manage contacts too.

02

You stay in control

Read-only or full access

Choose when you connect. Read-only lets the assistant look; full access lets it manage things for you.

  • Read-onlyReads, but cannot send, move, change or delete anything.
  • Full accessReads and manages your mail, events, reminders and contacts.

Revoke any time

Disconnect an assistant from your account page whenever you like.

03

Connect

  1. Add the connectorIn Claude, open Settings, then Connectors, and add a custom connector with this address. https://mcp.ibridge.fyi/mcp
  2. Sign in with AppleClaude opens the ibridge sign-in page. Sign in with Apple there.
  3. Choose a planSubscribe for US$1.99/month or US$19.99/year. Tax is added at checkout.
  4. Connect iCloudEnter your iCloud address and an app-specific password, never your main Apple ID password. Tick “Read-only access” if the assistant should only read. You can revoke it any time.

Claude Code

Add ibridge with one command.

claude mcp add --transport http ibridge https://mcp.ibridge.fyi/mcp

Other assistants that support MCP sign-in connect the same way, with the same address.

06

Questions

Is ibridge made by Apple?

No. ibridge is an unofficial service. It is not affiliated with or endorsed by Apple. iCloud is a trademark of Apple Inc.

Which assistants can use it?

Claude, and other AI assistants that support MCP sign-in. In Claude Code, add it with one command.

Can my assistant change or delete things?

Only with full access. Choose read-only when you connect if you only want it to read. You can revoke access any time from your account page.

Which password do I give it?

An app-specific password, never your main Apple ID password. It is stored encrypted under a key only your connected app holds.

How much does it cost?

The hosted service is US$1.99/month or US$19.99/year, with tax added at checkout. Running it yourself is free.

Can I run it myself?

Yes. ibridge is open source under Apache-2.0. Run it locally in Claude Desktop (.mcpb) or Claude Code, or self-host it with Docker. The code is on GitHub.
